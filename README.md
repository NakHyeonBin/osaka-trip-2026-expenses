# 오사카 여행 지출 정산 (2026-11-12 ~ 11-14)

영수증 15장을 품목별로 정리하고, 누구 몫인지 나눠 본 대시보드입니다. 금액은 일본 엔(¥) 기준입니다.

- `일본여행_지출_대시보드.html` — 대시보드 (`index.html`은 이 파일로 넘겨 주는 입구)
- `일본여행_영수증_품목별정리.csv` — 품목별 원본 데이터 (지출자 열 포함)
- `일본여행_영수증_품목별정리.xlsx` — 지출자를 정리한 엑셀

## 분담 규칙
- `NH`, `YH`: 각자 개인 지출
- `공동`: NH·YH가 1/2씩
- `4인`: 우리 2인분(NH·YH 각 1/4) + 동행 2인분(1/2)
- `동행`: 동행 2인이 전액

영수증 사진은 저장소에 포함하지 않았습니다.
